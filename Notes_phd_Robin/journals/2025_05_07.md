- ### Thoughts #[[Outlier Detection]]
	- La totalité des RNN qui font de la détection d'anomalies sur des séries temporelles utilise un LSTM qui est entrainé uniquement sur des données non aberrantes (inliers). Le problème est que l'on dispose de données réelles qui contiennent un mélange inconnu de comportements normaux et anormaux.
	  Pour palier ce problème, plusieurs pistes sont explorables:
		- Entraîner un auto-encodeur (ou LSTM-AE) sur l'ensemble des données; puis itérativement élaguer les points à forte erreur de reconstruction (anomalies potentielles); réentraîner le modèle sur le reste. 
		  -> Robust PCA / Isolation Forest / DRAE (Deep Robust AutoEncoder)
		- Appliquer un filtre non supervisé classique pour éliminer les outliers clairs. Conserver les 90-95% plus centraux pour entraîner le LSTM.
		  -> Mahalanobis depth, k-NN distance, Isolation Forest
		- Appliquer un culstering préalable, les points isolés sont mis de côté. Entraîner le modèle sur les clusters principaux.
		  -> DBSCAN, k-means
		- Ajouter à l'auto-encodeur un terme de régularisation dans la fonction de perte, pour forcer le modèle à ignorer certaines anomalies pendant l'apprentissage.
		  -> Dropout adaptatif, pertes pondérées où seules les erreurs faibles ont de l'importance dans la mise à jour des poids
		- Utiliser une méthode externe pour classer les points comme normaux ou anormaux
	- J'ai mis en place une **méthode deep LSTM** pour la détection d'outliers:
		- Trouver les 95% spectres les moins aberrants dans la base de données et les conserver pour la phase d'entraînement du modèle RNN:
			- Réduction de la dimension en effectuant une ACP sur les données spectrales qui conserve 99% de la variance
			- Calculer la **distance de Mahalanobis** de chaque spectre dans l'espace réduit en utilisant la matrice de covariance empirique
			- Fitter une distribution chi-deux sur la distribution des distances de Mahalanobis. Utiliiser comme seuil de décision le quantile d'ordre 95% d'une loi du chi-deux à p ddl, où p est le nombre de variables dans l'espace réduit.
		- Entraîner un **auto-encodeur LSTM** sur les spectres normaux:
			- Pré-traitement Min-Max des spectres
			- Entraînement d'un  auto-encodeur LSTM avec une seule couche latente de dimension 64
			- Les hyperparamètres du modèle (time steps, nb epochs, batch size, latent dimension, threshold percentile) sont pour le moment fixés par défaut, mais feront plus tard l'objet d'une optimisation si besoin.
			- Évaluation de l'erreur de reconstruction de tous les spectres de la base de données
			- Les outliers sont les spectres ayant une erreur supérieure à un seuil fixé (paramètre threshold percentile)
		- Dans l'article qui m'a servi d'inspiration, au lieu de fixer un seuil de décision sur l'erreur de reconstruction, ils apprennent une règle de décision à partir de méthodes appelées *OC-SVM* et *SVDD* avec une phase d'optimisation commune au LSTM et à une de ces deux méthodes.
		  Ces méthodes sont complexes et méritent une investigation approfondie avant d'être implémentées.
